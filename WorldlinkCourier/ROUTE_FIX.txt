WORLDLINK RECEIPT ROUTE FIX

The screenshot proves Flask is still rendering the old receipt/base template.
The new receipt template is deliberately named admin_receipt.html so it cannot collide with the old receipt.html.

In app.py, find the function:

def shipment_receipt(shipment_id):

Keep the login and shipment lookup exactly as they are, but replace the final render_template block with:

    return render_template(
        "admin_receipt.html",
        shipment=shipment
    )

So the complete route should be:

@app.route("/admin/receipt/<int:shipment_id>")
def shipment_receipt(shipment_id):
    if not session.get("admin_logged_in"):
        return redirect(url_for("admin_login"))

    shipment = Shipment.query.get_or_404(shipment_id)

    return render_template(
        "admin_receipt.html",
        shipment=shipment
    )

IMPORTANT:
1. Put admin_receipt.html inside the project's templates folder.
2. Do NOT use {% extends "base.html" %} in admin_receipt.html.
3. Stop the Flask server with CTRL+C.
4. Start it again from the actual WorldlinkCourier project folder:

5. Open the receipt again.
